Layer 1
Data Foundation — Reason-Code Normalization Service
Maps inconsistent legacy flag inputs into a fixed taxonomy (LOCATION_ANOMALY, DUPLICATE_CHARGE, AMOUNT_EXCEEDS_THRESHOLD, DRIVER_DISPUTE, UNKNOWN_LEGACY). Reprocesses legacy inputs at ingestion without rewriting historical DB.
Eng Fin Ops
Layer 2
Core Review Workflow — Filterable Queue & Case Action Drawer
Filterable case queue, detail drawer with normalized context, owner assignment, approve/reject actions with mandatory reason codes.
Ops CS Fin
Layer 3
Audit & Compliance — Immutable Append-Only Log & RBAC
Every state change is an append, never an edit. Role-based maker-checker permissions. Non-negotiable scope (Sprint 2).
Compliance Fin
Layer 4
Architecture Constraint — Shared Backend + Partner Frontend Config
Shared backend microservice logic; partner-configurable branding, labels, and per-partner reason codes. Governs Sprints 1–3.
Eng CS
Layer 5
Reasoned Deferrals — Explicit MVP Exclusions with Rationale
Deferred to protect pilot focus: CSV export (Part D trigger), Tokenized Cards, Receipt OCR auto-matching, AI Auto-Approval, AI-Assisted Triage.
